# GameVault - Frontend

React + TypeScript frontend for **GameVault**, a game review and backlog tracker (ITS2020 RAD final coursework).

- **Backend repository:** https://github.com/Neon2598-bit/RAD_Coursework_Gaming_Vault_Backend
- **Live frontend:** `<add Vercel URL>`
- **Live API:** `<add Render URL>`

## Technologies

React (functional components + hooks), TypeScript, Vite, TailwindCSS, Redux Toolkit, React Router, Axios.

## Setup and run locally

1. Install packages: `npm install`
2. Copy `.env.example` to `.env` and set `VITE_API_URL` (default `http://localhost:5000/api`)
3. Start the backend, then run `npm run dev`
4. Open http://localhost:5173

| Command | What it does |
|---|---|
| `npm run dev` | Starts the dev server |
| `npm run build` | Type-checks and builds for production |
| `npm run preview` | Previews the production build |
